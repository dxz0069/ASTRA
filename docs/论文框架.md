## 1. 命题（Thesis）

**状态资产化已是安全 Agent 的行业共识（引用证据成立），而固定时间窗赛制暴露的"经济性调度"是无主之地（我们的贡献）。**

拆开说：
- 共识部分：把"世界状态"从模型回忆变成系统资产（黑板/事实图/Memory Board）——两届 TCH 全部 Top 方案殊途同归，
  独立 AI 评审收敛于极简协议方案，平台方工程报告（Anthropic Managed Agents）同向。我们不 claim 这个共识，**我们引它**。
- 贡献部分：TCH 类赛制按解题率计分，公开语料里**没有人系统研究过固定时间窗吞吐赛制下的调度经济学**——
  defer 是期权价值保全、hint 是带价信息购买、部分旗收割是边际收益再投资、开题顺序是组合优化。
  ASTRA 在真实平台八轮实测上把它做成了显式、可调、可消融的机制族。这是论文的主张。

## 3. 贡献声明（C1–C4）

- **C1（核心）时间窗经济性调度**：首个把安全 Agent 赛制的调度决策统一建模为预算优化问题的公开工作。
  形式化四机制：defer 预算 `B = 2 + 2·flags_correct + hard + facts_depth`（上限 8）＝期权保全；
  hint 门控（无新旗 15/30min 才购买）＝信息购买阈值；多旗收割（部分旗不关题、保留进度回队）＝边际收益再投资；
  easy→hard 开题序＝期望得分排序。实证：八轮真实平台纵向记录（R1–R8，13470 分/48 旗峰值）。
- **C2 最小 Harness 纪律的操作化**：把"控制三分法"（能力缺口/信任缺失/经济性）从经验论断变成
  可执行的工程守则（`container/AGENTS.md` 已落地：新增控制必须归类，信任缺失类默认不加）。
  引 l3yx 三分法为出处，我们的贡献是**纪律化 + 全量现存控制的归类体检**。
- **C3 记忆的经验复利模型（形式化 + 路线图）**：用平台方情报切割框架 E[findings]≈N·∫p(x)q(x)dx
  （x=目标特征，p=目标分布，q=经验覆盖分布）形式化"跨题经验注入"的价值：注入=改变 q 使其逼近 p。
  四层记忆系统为该模型的实施路线图（future work 位）。
- **C4 黑板协议的并发模型实证**：多 worker = 并发探索而非角色分工（引 Anthropic 多 Agent 复盘 + l3yx 论断），
  证据：同构 worker 舰队 + 星图 stigmergy（defer 回队收割依赖且仅依赖信息素轨迹，不依赖会话记忆）。

## 6. 核心形式化（C1 展开）

计分模型：`Score = Σ_i v_i · f_i(t)`，f_i=题 i 在剩余时间内的期望旗产出率；调度目标 = 窗口内 Σ 最大化。
- **defer**：期望边际产出 < 队列中次优题的期望产出 → 保全进度出队（期权价值）；预算 B 随已证价值（旗数/事实深度）单调增——
  "已证明能产出的题优先续投资"，与 MCTS exploit 项同型（可引 UCB 类比）。
- **hint 购买**：hint 价值 = 解锁概率增量 × 题分值 − hint 分值成本；门控条件（无新旗时长）是"卡住信号"的代理变量。
- **多旗收割**：n/m 旗不关题，等价于把单题拆成 m 个可部分兑现的子期权；defer 预算的 2·flags_correct 项即其定价。
- **消融矩阵**：{defer 预算, hint 门控, 多旗收割, 开题排序} × {on/off} 的 2⁴ 设计（实际跑 6–8 个关键组合），
  平台轮次成本约 6–8 轮，按 BSRC 赛程窗口排期。

## 7. 实证计划

1. **纵向数据**：R1–R8 历史轮次（progress 文件 + 成绩记录）做机制上线前后的断点分析（defer 修复 vs R5、多旗收割 vs R9）。
2. **消融**：见 §6 矩阵；托管轮名额允许时执行。
3. **对照叙事**：同平台公开榜单 Top 打法（deepseek-flash 吞吐流）作为"无经济层的纯吞吐"对照组讨论。
4. **证据伦理**：只引公开可查数据（榜单/公开题 API/作者公开复盘），私有日志脱敏。

## 8. 威胁效度（ preemptively ）

- 单平台单赛制（Tsecbench）：泛化到解题率赛制的讨论放 limitation；
- 模型混合变动（R1–R8 间 fleet 有调整）：断点分析只比较相邻轮、机制差异单列；
- 分数上限效应：吞吐打法在题目无限供给时退化，注明适用域为"固定窗口 + 有限题库"。
