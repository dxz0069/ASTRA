# 榜首差距分析：Cairn_X(94.61) vs ASTRA(最好 47.92)（2026-08-28）

> 数据：榜首 run 7082 全量 1029 会话元数据 + 4 题完整对话（dist/rivals/7082_*）；
> 我方 dist/local-run*.log 九轮 + 托管 R8 记录。分析脚本存 note/tmp_analyze/（可重复）。
> 环境口径分列：本地轮（slot 受限）与托管轮（无 slot 限制）是两种病，不混诊。

## 1. 一句话结论

**能力差距不在引擎同源性（同出 Cairn 内核），而在四个行为差**：并发供给、会话颗粒度
（无状态短会话 vs 长驻）、止损闭环（drop_step+整图重置 vs defer 排队）、难题持续投入
（51% 会话堆 7 道题 vs 均匀撒网）。全部可在现架构上吸收，不需要推倒重来。

## 2. 榜首画像（run 7082，5.9 小时，71/74 旗）

- **节奏**：前 2.5 小时收 56/63 题；63 题全部在开局 **97 分钟内完成首触**（广度扫盘）；
  38 题 <5 分钟收尾；峰值并发 **12 会话**。
- **投入分布**：每题中位 8 会话；f2-05=116、b-02=105、a-16=73、b-03=69、b-01=62、a-18=56、
  c-03=47——**51.3% 的会话投在 7 道难题**（易题秒收省出预算）。
- **会话颗粒度**：中位 55s（判官池中位 15s / 执行池 108s）；36% 会话 <30s；
  每会话 12.3 次调用；**cache_read 占 91.3%**（382.9M）——无状态短会话+全图冷启动重建
  把 token 几乎全走缓存。
- **双角色池（与我们的 reason/explore 同源）**：判官（444 会话：satisfy_goal/drop_step/
  preview/commit，事务式图写入，只规划眼前一步）；执行（585 会话：bash/read/write/
  submit_fact，恰好一条事实收束，负结果也是有效结论）。
- **模型**：100% deepseek-v4-flash（蜂群成本结构，零昂贵模型）。

## 3. 榜首的四个关键行为（对话实证）

1. **整图重置策略**：14 题的 fact_origin 有 2-4 个时间戳——卡死就**丢图重来**（f2-05 四次
   重置），重烧题全部在重置列表里；末次重置后 b-01 36 分钟收 4/4、c-03 8.6 分、a-16 13.3 分。
   我们 defer 是"保留进度回队"——对已被污染/死锁的图，**清图比保图快**。
2. **drop_step 秒裁**：判官随时裁死方向 + 负结果 fact 归档，止损粒度是"步"不是"题"。
3. **平台元博弈**：提交 API 语义（duplicate/flag_index/correct_flag_count）进 fact 当知识；
   hint 端点本身当跨题探测对象（f2-05 step_025 原文"对照 b-02 的 hint 结构确认平台提示机制"）；
   一个 step 连提 8 个候选 flag（错误提交零惩罚被其利用）。
4. **提交不走专用工具**：执行 agent 直接 bash 跑 python/curl POST 提交端点（env 注入 token），
   回执 JSON 原文进 fact 作见证；判官 satisfy_goal 引官方回执收口（correct:true/awarded/
   correct_flag_count）——**收口有见证凭证**。

## 5. 差距根因排序（按证据强度）

1. **跨 run 经验复利差距（最大且最根本）**：作者在同一平台跑了数十轮（run_id 7082 vs 早期
   6xxx），workspace/提示/打法逐轮蒸馏；我们的知识库对 tsecbench 题码为空——经验复利
   轮数为 0。**同样的引擎，人家带着题库记忆跑，我们裸跑。**
2. **会话/上下文架构**：无状态短会话+全图重建（91% 缓存、图永远干净）vs 长驻项目
   （上下文随轮次膨胀、缓存效率低）。
3. **止损粒度与图卫生**：步级裁撤+整图重置 vs 题级 defer 保图。
4. **难题投入分布**：51% 会话堆 7 道难题（易题秒收腾出预算）vs 我方均匀分配。
5. 并发供给（托管已缓解；本地轮是主要病灶）。

## 6. 作者的 tsecbench 适配改装（实证/推测分列）

**实证**：纯 flash 蜂群成本结构；平台围栏直接用平台模板（fact_origin 注入）；提交/hint
端点语义当跨题知识；广度扫盘开局；14 题图重置。

证实分钟级到账；图重置后快速收敛暗示重置图携带蒸馏先验或人工介入（仅相关性证据）。
