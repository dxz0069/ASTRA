# 演示视频脚本（≤5 分钟）

> 录制建议：本地环境 + local 模式 + mock/演练靶场；全屏录制终端与星图面板。
> 旁白为中文，节奏紧凑，突出"无人值守 + 机制保障"。

## 分镜

### 0:00–0:30 开场：一句话定位
- 画面：ASTRA 星图界面（星记节点逐步生长）
- 旁白：ASTRA 是一套 AI 攻防全链路 Agent——给定起点与目标，它在状态空间中自主搜索路径。从题目下发到成绩回收，全程无人值守。

### 0:30–1:30 核心机制一：星尘记忆（上下文治理）
- 画面：切到终端，展示一次定航（reason）的 prompt 内联段；再展示大项目下内联量仍被预算截断
- 旁白：每次推理只内联与当前目标最相关的焦点子图；超预算的旧星记自动压缩为摘要。上下文不随任务变长而膨胀。

### 1:30–2:30 核心机制二：双星决策（对抗审查）
- 画面：展示一次提案被质询（challenge）输出反驳意见、修正后裁决（verdict）通过写回的过程；再展示一次被否决的提案及否决原因沉淀
- 旁白：关键决策不靠模型自觉——先机器预审，再由独立质询视角挑毛病，最后裁决。被否的方向会变成指引，避免原地打转。

### 2:30–3:40 实战演示：一道 SRC 场景题
- 画面：跑 astra-runner 实战；展示题目启动 → 星图生长（扫描、指纹、注入点）→ flag 星记出现 → 平台提交返回 correct → 题目关闭进入下一题
- 旁白：靶场地址自动注入项目；引擎并行探索 Web/利用/内网多航向；flag 由编排器统一提交，幂等防重；每题完成后自动释放资源。

### 3:40–4:30 机制与工程保障（不贴当前战绩——水平还在迭代，托管实测出分后再放）
- 画面：贴混合舰队结构图 + 稳定性机制清单（开题排序/分级提示/断点续跑/watchdog）
- 旁白：焦点子图与混合多模型控制成本；证据链与质询过滤误报；开题排序与断点续跑保障长窗口满载；人机验证时间比例趋近于零。

### 4:30–5:00 收尾
- 画面：ASTRA 星图全景 + 赛道六维图标
- 旁白：星图导航、双星决策、星尘记忆——ASTRA 让 AI 攻防从经验驱动走向机制保障。谢谢观看。
