## 五、评委问答预案（现场答辩维度，预演 10 问）

1. **"和商用渗透 Agent（XBOW 类）比，你们差距在哪？"**——单兵能力他们强（更强模型+更全工具链）；我们的差异在**系统会变强**：他们的知识是专家静态注入，我们的知识每场实战自动生长。两个路线不冲突，复利是我们能讲十年的故事。
2. **"记忆会不会变成作弊/背题？"**——三重红线：托管评测预置记忆可一键合规清零（已实测）；全链路双层脱敏（知识库不含、不猜、不存 flag 值）；合并回库必须人工审核。记忆的是"打法与死路"，不是答案。
3. **"和通用记忆框架（Mem0/Letta 类）的本质区别？"**——它们是记忆中间件，不懂安全场景"什么值得记"；我们的记忆对象是攻击链（入口→漏洞→利用）与死路，记忆单元本身带渗透语义，且与调度经济学联动（战绩驱动开题预算）。
4. **"为什么不用多角色 SubAgent 分工？"**——并发是模型不是分工（踩过实测坑：角色锁死损失泛化）；星图协议让协作从共享状态里涌现，人类可随时写辅星干预，完整因果链可追溯。
5. **"幻觉/误报怎么控？"**——自证写回（跑过命令亲眼见过才入图）+ 有界质询星探（关键结论对抗审查，fail-open 不卡主链）+ 200+ 回归测试锁行为。
6. **"八轮 +54% 会不会是调参运气？"**——曲线背后每一轮都有归因档案（哪轮修了哪个机制、对应哪个维度涨分），可以现场翻 run 记录；且模型一行未换。
7. **"代码是自研吗？"**——基于一个 AGPL 开源状态空间搜索框架深度重构：六大子系统重造、八轮实战驱动迭代；星尘记忆管线、调度经济学层、自愈体系、合规开关均为自研。（诚实但不展开，主动权在自己）
8. **"部署门槛/数据安全？"**——local 模式单机可跑、零重依赖、支持全离线；星图与知识库全本地存储；已有 API 鉴权与请求面加固（12 轮审计）。
9. **"15 分钟外还有 什么是你们最想让评委记住的？"**——"跑一百次，比跑一次强。"（回一句话故事，闭环）
10. **超时拦截**——若被催时：直接跳 P11 量化表+P13 金句收尾（两页 90 秒讲完），牺牲场景页。
