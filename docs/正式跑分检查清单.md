## 2. 启动前自检（10 分钟）

```powershell
# Windows local 模式（本机联调）
powershell -ExecutionPolicy Bypass -File scripts\setup_dsh.ps1 -NoInstall
BENCHMARK_TOKEN=<平台token> BENCHMARK_BASE_URL=<平台url> \
ASTRA_WORKER_TYPE=dsh DSH_PROVIDER=deepseek DSH_MODEL=deepseek-v4-flash \
DEEPSEEK_API_KEY=<key> \
python container/astra_runner/runner.py --check
```
`[PASS]` 全过才开跑；任一 `[FAIL]` 按提示修复（常见：key 缺失 / patch 未复制进 dsh lib）。

  默认值已是 900/1800/2700，不传参数即生效。
