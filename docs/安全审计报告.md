## 手动逻辑审计（通过项）

- **runner 并发**：deque 方法线程安全（CPython GIL）；results/active dict 主线程写、_work 只写 result 字段；TaskFinishedError 经 stop_event 传播；daemon 线程随进程退出清理
- **flag 提交**：多线程提交靠平台幂等（DuplicateSubmit）+ flags_found 去重
- **dispatcher**：每任务 TaskCancellation；rejected/failed 冷却防风暴；heartbeat 过期清理
- **consolidate**：archive 先清 intent_sources 再删 facts；引用失效安全失败（404）
- **前端**：0 处 x-html（无 XSS 注入面，全部 x-text）；删除有 confirm；api() 统一错误处理
- **配置**：`extra="forbid"` 严格校验；context_budget 默认值保护

## 已知限制（接受）

1. 本地 API 无认证（本机单用户定位）
2. 审查不可用时降级放行（可靠性权衡，已记录 hint）
3. prompt 注入面（无认证写入 + LLM 读取）——赛事本地环境可接受
