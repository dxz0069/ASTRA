## 六、实现路径（9:30–11:00）

**技术选型与理由**（讲"为什么不用 X"最显功力）：
- 存储选 SQLite + Markdown 而非 Neo4j/向量库——"量级万级以内，零运维零依赖，评测环境即开即用；接口抽象了，量起来可平滑换"；
- 语义召回用 API/本地模型双通道 + 熔断降级——"任何记忆组件失败都不阻断主流程，工程可靠性优先"；
- 记忆压缩用轻量模型（Epitome）——"记忆操作不需要旗舰模型，成本可控才能高频运行"。

**三个真实难点与解法**（挑讲，每个 30 秒）：
1. **上下文膨胀**：全量历史内联导致 token 线性爆炸 → 焦点子图裁剪 + 摘要压缩，内联量恒有硬上限（零膨胀）；
2. **经验噪声**：自动沉淀的攻击链可能污染知识库 → 双层脱敏 + 质询对抗审查 + 冲突检测（同题新旧打法差异显著时双版本保留、战绩裁决）；
3. **任务内死锁**：单题死磕拖垮整场吞吐 → defer 机制（无果放回队尾续跑）+ 期望预算（有历史耗时参考的题动态调整限时）。

## 七、企业落地场景（11:00–13:00，企业评委最买账的部分）

1. **企业红队/渗透测试自动化**：资产测绘→漏洞验证→利用链复现全流程，星图天然是证据链，一键导出中文渗透报告（开发中）——直接对齐甲方交付物；
2. **安全经验资产化**：企业每年雇红队/买众测，报告看完就扔。ASTRA 把每次实战沉淀为企业私有攻击链知识库，**供应商换了、经验留下**——这是安全建设从费用变资产的路径；
3. **常态化安全验证**：记忆系统让重复测试越来越快越来越准，适合等保/护网前的周期性自检；
4. **安全团队培训加速**：新人的成长周期 = 踩坑周期；失败经验库把组织的坑变成新人开局即有的避坑指南。

**迭代路线**：赛后报告生成器（星图→渗透报告）→ 多机协同内网横向（打点后横移，星图天然支持跨项目共享侦察事实）→ 记忆联邦（多队伍/多企业脱敏经验交换与社区命中率榜）。

## 八、评委 Q&A 需案

| 可能问题 | 回答要点 |
|---|---|
| "误报/准确性怎么保证？" | 质询对抗环（独立审查者否决漂移提案）+ 置信度分级 + 人在环（赛后审核草稿） |
| "记忆污染怎么办（错误经验被强化）？" | 战绩闭环：错误经验未命中自动沉底；冲突检测双版本保留；审核权在人 |
| "和商业产品比能力差距？" | 单兵能力有差距，但能力可以买、**经验复利买不到**；且记忆层可叠加在更强模型上（模型无关） |
| "数据安全/合规？" | 双层脱敏红线 + 全隔离容器执行 + 自托管（数据不出企业） |
| "幻觉风险？" | 星记必须带证据写入、flag 必须实测获得，知识库明确标注"方向参考非答案，必须实测验证" |
| "为什么不直接用 Mem0？" | 通用记忆中间件不懂安全语义（什么值得记/记成什么结构），我们的记忆单元就是攻击链 |
