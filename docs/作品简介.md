# ASTRA·星辰 —— 经验复利型自主安全智能体

## 作品简介

ASTRA 是一个面向 AI 攻防全链路的**自主安全智能体系统**。不同于"更强单次执行"的常见路线，ASTRA 的核心命题是：**让安全 Agent 拥有记忆，越用越强。**

当前安全 Agent 普遍是"金鱼"：单次任务内上下文超限即失忆、关键信息被冗余输出淹没，跨任务经验直接归零——跑一百次和跑一次一样笨。ASTRA 以认知科学的记忆理论为骨架，构建了**仿生四层记忆系统"星尘记忆"**：瞬时记忆（会话原始上下文）→ 工作记忆（焦点子图智能裁剪，零上下文膨胀）→ 短时记忆（星图事实库 + Epitome 自动摘要压缩）→ 长时记忆（攻击链自动沉淀、脱敏固化、开局注入）。

在此之上，星尘记忆具备**七件进化机制**，使经验形成完整闭环：

- **语义召回**——词面 + 语义向量混合检索，同义经验不再漏召回；
- **回忆强化 / 遗忘曲线**——每条经验带实战战绩注入（如"3 次命中/0 次未命中"），高频有效打法自动上浮，长期无效条目自然沉底；
- **举一反三**——无原题时按题型自动注入同类型历史打法，按战绩加权；
- **赛中实时复利**——一场比赛中，先前解出的题目即时沉淀并热加载给后续题目，**同一场比赛内 Agent 就在变强**；
- **失败经验库（负记忆）**——不只记住成功：走不通的死路同样沉淀，同类题目开局即获"前车之鉴"避坑提示；
- **赛后自动蒸馏**——自动产出新经验条目、旧条目修正建议与新技能骨架三件草稿，人工只审核不搬运，技能库实现自我生长。

系统底座为自研"星图导航引擎"：以**星记（事实）、航向（意图）、指引（提示）**三类原语对未知目标进行状态空间搜索；关键结论须经独立"质询星探"对抗审查方可入图，配合决策链全程留痕与一键回放（`astra memory trace`）、星图可视化（`astra memory map`），实现**每一步决策可审计、可解释**。全链路执行双层脱敏红线：经验库不含、不猜、不存 flag 值。

正面经验给方向、负面经验防重蹈、赛中实时生长、赛后自动结晶——ASTRA 将安全 Agent 从"一次性工具"进化为**持续积累实战经验的复利型系统**，这是与现有产品的根本机制差异。
