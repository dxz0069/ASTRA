# ASTRA 优化路线图：架构特点 × 论文对照

> 2026-08-24。基于代码实勘（任务管线/双星审查/worker 舰队/调度循环）× 2026 前沿论文。
> 每条 = 我们的机制现状 → 论文对应发现 → 具体优化（含落点）。

## 特点 1：双星审查（challenge→verdict 对抗环）——我们的独门，还能更强

**现状**：reason 提案与 low-confidence 事实写图前必过审查；机器预检（低置信证据即拒、flag 无凭据即拒）→ 质询者（≤5 条反对意见、须引星图证据）→ 裁决者（须逐字复述原提案才通过）；审查基础设施故障降级直通。

**论文对照**：多智能体辩论/自反思文献的共识发现——**同模型自审相关性误差高，跨模型评审去相关**。PentestGPT v2 用独立审查但未系统化；我们已超出他们，但评审者选择（`_resolve_review_worker`）优先用**提案者同款 driver**——恰好是误差相关性最高的配置。

**优化**：评审异构化——质询阶段尽量路由到**不同提供商**的 worker（dsh 提的案用 claudecode 审）。零代码量（改 `_resolve_review_worker` 优先级），预期显著降低橡皮图章率。**答辩前可做，2 小时。**

## 特点 2：reason 战略层（max_intents=3、失败学习标记、独立可并行航向）

**现状**：reason 按触发条件跑（事实增长/hint 增长/航向清零），提出 ≤3 条不重叠航向；[失败学习]/[审查否决] 方向禁重提。**没有航向价值估计、没有系统性回溯**。

**论文对照**：PentestGPT v2 的 EGATS（MCTS+UCB+难度惩罚）消融 +9pt；行为学上 v2 回溯率 34% vs 基线 8%、换向更早（depth 5.1 vs 12.4）。

**优化**：轻量 UCB 进 reason prompt——给每条 open intent 附上"已投入 explore 次数/产出事实数/最后心跳"三元组（数据全在星图里，渲染进 reason.md 即可），提示模型显式做 explore/exploit 权衡与提前换向。不动调度核心，纯 prompt 增强。**赛后做，1 天。**

## 特点 3：explore 证据契约（可重放命令、置信度分级、增量写回）

**现状**：high 置信须亲自跑过命令；evidence 字段要求"完全可重放的命令"；重复检查 Jaccard 0.6。

**论文对照**：Deterministic Legal Agents（arXiv 2510.06002）的核心思想——**把 LLM 主张挂在确定性原语上验证**，而非再找一个 LLM 仲裁。我们的机器预检只有正则级。

**优化**：**证据重放服务**——对 complete 提案（最关键时刻）自动重跑 evidence 里的命令，输出比对。把"flag 声称有凭据"从正则匹配升级为实测复验。答辩讲点是"确定性验证层"；工程上复用 worker 容器跑一条 shell。**赛后做，2 天，谨慎放量（只 complete 场景）。**

## 特点 4：consolidate 星尘压缩（最旧批次→单段摘要→归档）

**现状**：按"最老且未被航向引用"选批，压成一段 summary，归档原件。

**论文对照**：Infini Memory——**主题聚簇优于时间批次**（相关证据集中维护、去重自然）；**修订语义**（事实变化时覆盖+元数据，而非只追加）；消融显示主题化维护与迭代检索各贡献独立增益。

**优化**：① 选批从"最老"改"同主题优先"（用我们的 `_categorize` 按主机/服务聚类，一网段一批）；② summary 与新事实矛盾时触发重压缩（修订），而非双存。**赛后做，1-2 天。**

## 特点 5：异构 worker 舰队 + 按任务类型路由

**现状**：dsh/claudecode/codex/pi 各声明 task_types+priority，便宜模型跑 reason/consolidate/review、强模型跑 bootstrap/explore；心跳租约+风暴冷却。

**论文对照**：PentestGPT v2"架构收敛"发现——大量架构是 2023 模型局限的补丁，GPT-4o→GPT-5 后系统间差距压缩过半。启示：**别把工程押在补模型短板上，押在模型不会变强的东西上**（记忆/验证/调度——我们恰好在做对的事）。模型路由/cascade 研究则支持按难度动态升降档。

**优化**：难度感知升降档——TDI 高的任务路由到高推理档（DSH_REASONING_EFFORT 已支持档位切换，只差触发信号）。与特点 7 的 TDI 合并实施。**赛后做。**

## 特点 6：graph.yaml 两层注入（文件引用 + review_graph_summary 摘要）

**现状**：worker 拿全图文件路径自读；审查阶段附内联摘要（goal≤200 字+前 15 facts+8 intents）。

**论文对照**：Infini Memory 的 agentic retrieval（迭代式读记忆胜过一次性 top-k）；AT2QA（arXiv 2603.01853）"让 agent 自主探索图胜过固定工作流"——**我们的文件引用设计已被论文验证方向正确**。缺的是第一层的"结构"：摘要按 id 顺序截断，不是按语义组织。

**优化**：**状态卡片**——把 review_graph_summary 升级为结构化战况卡（主机/端口/凭据/会话四类正则聚合，常驻）+ 主题索引（每航向一行），全文仍走文件。**答辩前可做，1 天，PentestGPT v2 记忆消融 +8pt 的直接对应物。**

## 特点 7：期望预算/defer/hint 购买三个 ad-hoc 决策

**现状**：期望预算（KB 历史耗时→限时）、defer（45min 无果回队）、hint 购买（15/30min 无果）各自为政。

**论文对照**：PentestGPT v2 的 TDI 四维（horizon/证据置信/上下文负载/历史成功）统一驱动剪枝与策略切换；上下文 >40% 负载准确率崩（90→61%）。

**优化**：合成任务难度指数 TDI_ASTRA = 历史成功率 + 当前证据置信分布 + 上下文占用率，统一驱动三机制 + 特点 5 的升降档。**赛后做，2 天——把三个补丁收敛成一个有论文出处的原理性设计。**

## 特点 8：runner 并行窗口 + 跨题记忆注入（V4/V5）

**现状**：easy→medium→hard 防饿死、精确码注入+同题型邻居+避坑、赛中热加载。

**论文对照**：CTFExplorer 多目标范式（跨题状态共享是真实渗透的核心能力，学术界刚开始做）；我们领先。

**优化**：跨项目事实共享（同内网侦察结论复用）——星图 schema 天然支持，Tsecbench 场景内直接可用。**赛后，1-2 天，对多题同网段场景增益明显。**
