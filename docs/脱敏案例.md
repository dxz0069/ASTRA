# 脱敏漏洞实践案例

> 以下案例基于本地靶场演练（模拟 SRC 众测场景），所有目标均为授权环境，数据已脱敏。
> 展示 ASTRA 从"起点"到"归航"的完整解题路径与关键机制。

## 案例一：Web 应用 SQL 注入 → 数据提取（WEB / EXPLOIT）

**起点（Origin）**：`http://10.0.0.12:8080`（授权测试站）
**目标（Goal）**：获取应用数据库中的 flag

**解题路径（星图轨迹摘要）**：

1. **首探（Probe）**：nuclei 快速指纹识别 → 确认目标为 WordPress 5.2 + 插件存在已知注入点；
2. **定航（Navigate）**：质询后批准两条并行航向——「插件 SQL 注入利用」与「后台弱口令探测」；
3. **巡猎（Patrol）A**：sqlmap 验证注入点，确认 `login` 参数存在时间盲注，星记写回（置信度 high，证据附 sqlmap 输出片段）；
4. **巡猎（Patrol）B**：弱口令未果，被质询否决后释放算力，失败教训写入指引；
5. **裁决（Verdict）**：注入利用产出被质询——「盲注无回显，需确认数据是否真实存在」；修正后补充带外验证（DNS 外带），裁决通过；
6. **归航（Complete）**：提取数据库 `flag{...}` 写回星图，平台提交返回 correct，项目完成。

**机制体现**：多航向并行、低置信产出被质询修正、失败教训复用、flag 证据链完整。

## 案例二：多层网络横向移动（KILLCHAIN）

**起点**：边界 Web 服务器（唯一公网入口）→ **目标**：内网域控上的 flag

**路径**：边界 getshell（CVE 利用）→ chisel 建立隧道 → proxychains 内网扫描 → netexec 横向（SMB 口令复用）→ 域用户提权 → 域控读取 flag。

**机制体现**：攻击链以星记-航向链式沉淀，横向移动每一步都有证据（命令与输出）；断链时 reason 检测方向偏差并重定向。

## 案例三：Python 反序列化沙箱逃逸（真实靶场实战，已脱敏）

**起点**：授权评测平台下发的代码执行服务（接受用户提交的 Python 代码并在受限环境运行）
**目标**：绕过执行限制读取 flag

**解题路径（引擎星图轨迹，全程无人值守）**：

1. **首探**：探测服务接口与限制——`import os` 等直接路径被白名单拦截；
2. **定航**：识别为 Python 沙箱逃逸类，批准「内建链绕过白名单」航向；
3. **巡猎**：构造内建属性链 `getattr(int, '__base__') → object.__subclasses__()[索引]`
   定位 `os._wrap_close`，经其 `__init__.__globals__['popen']` 执行命令读取
   `/challenge/flag1.txt`，输出与证据片段写回星记；
4. **质询与裁决**：质询要求确认读到的字符串符合 flag 格式且非拼接产物，复核通过后写回；
5. **归航**：flag 星记由编排器统一提交，平台返回 correct。

**机制体现**：受限环境的攻击面枚举、内建链知识的高效调用、产出必经质询复核——
同类题型第二道（Node.js vm2 逃逸，CVE-2023-32314 原型链利用）在同轮被同机制直接解出，
体现方法复用性。
