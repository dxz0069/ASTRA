# ASTRA 0.3.0（星尘记忆满血）

> 2026-08-30。记忆管线补全：对照 `docs/作品简介.md` 目标状态逐句核验，已有机制不动，补齐 6 个缺口。分支 `astra-memory`（自 astra-fgs 切出），7 提交。定位：星尘记忆是 ASTRA 八大创新点之一，本版只动记忆管线，FGS 调度/舰队经济学/工具链等其余创新点零改动。

## 差距判定（文案 → 现状）

已存在不动：L2 焦点子图裁剪（context.py）、四类开局注入、回忆强化战绩、举一反三邻居加权、赛中热复利、失败经验库、双层脱敏、trace/map CLI、星图三类原语。

## 变更清单

### 遗忘曲线（17ff6af）
- `runner.py` `_recency_decay`：战绩权重 × `0.5^(距last_used天数/30)`；无记录 1.0。
- 邻居注入排序键 `(hits-misses)×decay`，同分按分值；`astra memory stats` 增加衰减后权重列。

### 沉淀卫生（85b82ac）
- 五个注入标记（历史思路/同题型经验/避坑/侦察共享/质询星探）在三个末段星记采集点与知识沉淀统一剔除——防知识库复读自己的注入文本（V8 轮 dead-ends 实见污染）。

### 语义向量持久化（cbedafc）
- `embeddings.py` SQLite sidecar（sha1 主键 + float32 BLOB）：重启免重算；默认 `~/.local/share/astra/vector-cache.sqlite3`（`ASTRA_VECTOR_CACHE` 可覆盖）；规模有界 20k 条删最旧、损坏自愈、`ASTRA_EMBED_PERSIST=0` 可关。熔断/降级语义不变。

### 赛后自动蒸馏（984bc22）
- 核心入包 `astra.distill`，`tools/distill_review.py` 改薄壳保 CLI 兼容。
- runner 收尾自动产三件套草稿（新条目/修正建议/技能骨架）至 progress 同目录 `review-drafts/`；`ASTRA_AUTO_DISTILL=0` 可关；异常全吞不影响退出码；合并仍走人工 merge_knowledge（"人工只审核不搬运"）。

### Epitome 图导出压缩（1a0c29b）
- `export.py`：事实数 > 阈值（`ASTRA_EPITOME_THRESHOLD` 默认 120）时，graph.yaml 折叠"老旧且脱离因果链"的浅层事实为单行首句 + `[Epitome]` 标记。
- 保留集：origin/goal、负结果、凭据/flag 级（复用 `_CRITICAL_RE`）、因果骨架（任一步骤来源或落点）、最近 30 条。原库零改动（只压缩导出视图）；`ASTRA_EPITOME=0` 可关。

### 质询星探（334a106）
- 新任务类型 challenge（`prompts/default/challenge.md` 极简英文 + mock 相位默认 uphold）。
- **complete 把关（同步）**：decide 判 Goal 满足后、写图前对抗审查；refute → 拒绝收束 + `[失败学习]质询星探` hint 留痕，搜索继续——拦多旗题提前收束，有提分潜力；任何质询故障 fail-open 放行。
- **关键事实审计（异步）**：凭据/flag 级事实入图后投递后台守护线程队列（≤16）异步质询，不阻塞旗提交；质疑成立写 `[质询星探质疑·关键结论]` hint 可回放。
- 有界纪律：每项目 4 次预算（`ChallengeTaskConfig.max_per_project`，两类把关共用）、计数器超 1024 清空、队列满丢弃；`ASTRA_CHALLENGE_MODE=0` 整体关。
- server 零 schema 变更（留痕走 hint）；质询超时默认 120s（`tasks.challenge.timeout` 可配）。

### 托管默认关 + 版本
- `Dockerfile.slim` ENV：`ASTRA_CHALLENGE_MODE=0 ASTRA_EPITOME=0 ASTRA_AUTO_DISTILL=0`——本地默认全开、托管跑分零开销，机制经本地轮实测后再开。
- 版本 0.2.0 → 0.3.0。

## 设计取舍

- L1 depth 字段不做：文案 L1/L2 已由现状满足，深浅分级语义并入 Epitome 折叠判据，避免 schema+提示词变更。
- 质询复活与 0.2 "审查不复活" 裁决的关系：本次为有界复活（只审 complete 与凭据级关键结论，fail-open，预算封顶），非 0.2 删除的全量审查链（confidence/evidence 字段不回来）。
- 向量持久化用 SQLite 而非 jsonl/FAISS：20k×2048 维全量进内存是 GB 级，SQLite 主键查询单条加载；零新增依赖。
